# Campus-Auth 一键安装器

给本校同学用的校园网自动认证工具，一个文件、双击就装好。

> 只负责**打包安装器**；本体程序来自上游 [Campus-Auth-rs](https://github.com/Misyra/Campus-Auth-rs) 的 GitHub Release。

---

## 怎么用

1. 拿到 `campus-auth-一键安装.bat`，**双击**。
2. 弹出「是否允许此应用对你的设备进行更改」→ 点「**是**」（这样开机和唤醒都能自启）。
   - 点「是」后会**新开一个管理员窗口**继续安装，最早那个窗口会一直等到管理员窗口跑完才关闭 —— 这是正常的，不是卡死。
   - 点「否」也不影响安装：会退回当前窗口继续（只是少了"唤醒自启"这一项）。
3. 按提示输入校园网**账号**与**密码**（密码会直接显示在屏幕上，方便核对；如介意可事后在程序里改）。
4. 等它自动下载、解压、配好。下载过程有进度跳动（已下载 MB / 百分比 / 速度 / 秒数），只要秒数在走就是正常，别关窗口。任务栏出现托盘图标即可用。

装在哪：默认 `D:\campus-auth`；没有 D 盘会装到 `%LOCALAPPDATA%\campus-auth`。

### 静默安装（可选）

```powershell
$env:CA_USERNAME  = '学号'
$env:CA_PASSWORD  = '密码'
$env:CA_ASSUMEYES = '1'    # 跳过所有确认
powershell -ExecutionPolicy Bypass -File campus-auth-onekey-setup.ps1
```

其他可选变量：`CA_INSTALLDIR`（安装目录）、`CA_NOLAUNCH`（装完不启动）。

## 下载慢 / 卡住怎么办

安装器会**自动依次尝试多个通道**，主程序与 uv 都是如此：

1. GitHub API 直下（`api.github.com` 的资产端点，校园网下通常最通）
2. github.com 直连
3. 加速镜像（`gh-proxy.com`、`ghfast.top`）

每个通道下载时都会实时刷新 `已下载 x/y MB (百分比)  速度 MB/s  已用秒数`；**秒数在走就是在下**。若某通道连续 60 秒没有新数据，会自动换下一个通道并打印原因，不会无限卡死。

## 自启动（安装器自动配好，不用管）

| 场景 | 是否自动启动 |
| --- | --- |
| 关机 → 开机 / 重新登录 | ✅ |
| 合盖睡眠 / 锁屏 → 唤醒解锁 | ✅（需第 2 步点了「是」） |

原因：程序自带的 Run 键只在登录时触发，**睡眠唤醒后不会补拉起**。安装器额外注册一个计划任务（任务名 `Campus-Auth Autostart`），补上唤醒这一格。

第 2 步点了「否」也能正常用，只是**唤醒后不自动启动**。想补上，右键安装器 →「以管理员身份运行」重跑一次即可。

---

## 启动时提示「缺失 SHA256 校验文件」

这是**上游发布打包的问题**，与安装器无关，**不影响使用**，忽略即可；上游补齐后会自动恢复更新。

---

## 双击后一闪而过 / 窗口自动关闭

别反复点，按顺序做，基本都能定位：

**1) 先量文件大小。** 右键安装器 →「属性」→ 常规 →「大小」，应和发送方手上原文件的字节数**完全一致**（当前版本 67,541 字节 / 66.0 KB，SHA256 `d3790872…9b7e17`）。
数字不对（0 字节、几十 KB 等）说明**文件在传输中被改动或截断**（微信 / QQ / 网盘 / 压缩工具都可能），让对方重发一次即可。

> 注意：微信/QQ 收到同名文件会自动改名成 `xxx(1).bat`、`xxx(2).bat`，**这是正常的，不影响运行**。

**2) 再看有没有留下痕迹。** 安装器会写三处痕迹，按这个表判断：

| 位置 | 文件 | 说明 |
| --- | --- | --- |
| 安装器**同目录** | `campus-auth-install.log` | **首选看这个**。完整诊断日志：系统版本、是否管理员、是否发起过提权、子进程 PID 与退出码、出错行号 |
| `%TEMP%`（地址栏粘 `%TEMP%` 回车） | `campus-auth-install.log` | 同上内容（双写备份）。提权换了账户时 TEMP 会变，此时只有同目录那份最准 |
| `%TEMP%` | `campus-auth-bat-started.txt` | **没有它 = 安装器根本没被执行**（被安全软件/系统策略拦下，或文件本身损坏）；有它则记着 PowerShell 的退出码 |

**怎么看日志判断卡在哪：**

| 日志里看到 | 含义 |
| --- | --- |
| 只有一行 `安装器启动`，后面是 `提权目标=…`、`已发起提权 PID=…`，**再无第二个「安装器启动」** | 管理员窗口没起来。把日志发回来即可定位 |
| `已发起提权 PID=…` 后面**有第二个「安装器启动」** | 提权成功，管理员窗口接上了 |
| `管理员窗口启动后 2.5 秒内即退出（退出码 …），判定提权未生效` | 管理员窗口秒退（早期"一闪而过"就是这个）。安装器会自动**在当前窗口继续装**，不会跟着闪退 |
| `管理员窗口已结束 退出码=0` | 管理员窗口正常跑完了 |
| `安装中止: …` | 主流程出错，后面紧跟具体原因和行号 |

**3) 想当场看到报错。** 右键开始菜单 →「终端(管理员)」或「Windows PowerShell(管理员)」→ 把安装器文件**拖进这个窗口** → 回车。这个窗口不会自己关闭，报错会全部留在屏幕上。

**4) 两个常见坑。** 关杀毒软件**只关面板不管用**，要把安装器加进信任区；从聊天/网盘收到的文件可能带「锁定」标记 —— 右键 →「属性」→ 底部勾选「解除锁定」→ 确定，再重试。

## 维护者：重新构建

```bash
python build_onekey.py
```

产出 `campus-auth-onekey-setup.ps1` + `campus-auth-一键安装.bat`（已在 `.gitignore` 忽略，发布时重新构建）。

| 文件 | 作用 |
| --- | --- |
| `build_onekey.py` | 构建脚本：模板 + 预设配置 → 独立安装器 |
| `onekey-template.ps1.tpl` | 安装器模板：解析最新 Release、多通道下载（API 直下 / 直连 / gh-proxy 镜像，带进度与停滞换源）、下载 uv 预置、写配置、注册自启动、启动托盘；UAC 提权交接（等待子窗口 + 秒退自愈）、诊断日志双写 |
| `preset-settings.json` | 真实运行的设置快照，让重建不依赖已安装目录 |
| `campus-auth-default-fixed.json` | 默认认证任务，账号/密码用 `{{USERNAME}}`/`{{PASSWORD}}` 占位符 |

## 换学校 / 自定义（一般用不到，本节放最后）

本项目**只为本校定制**，模板里的默认值已是本校参数，同学直接双击用即可。

若要给别的学校用，改 `onekey-template.ps1.tpl` 顶部这几项，然后重新 `python build_onekey.py`：

- `$AUTH_URL` — 认证页面地址（默认 `http://211.69.15.10:6060/portalReceiveAction.do`）
- `$ISP` — 运营商选项（默认 `本地账号`）
- `$API_URL` / `$FALLBACK` — 上游 Release 地址与固定版本回退链接
- `$CHANNELS` / `$uvChans` — 下载通道优先级：API 直下 → 直连 → 加速镜像（模板里按此顺序自动组装）
